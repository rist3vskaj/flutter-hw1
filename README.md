## Кототиндер — Домашняя работа №1

**Кототиндер** — это небольшое Flutter‑приложение, где можно свайпать случайных котиков, ставить им лайки и изучать список пород из API `thecatapi.com`.

---

### oписание проекта

- **Главный экран** показывает случайного котика с названием его породы.
- **Свайп или кнопки лайк/дизлайк** переключают котика на нового.
- **Счётчик лайков** увеличивается при свайпе вправо или нажатии на кнопку лайка.
- **По нажатию на изображение** открывается экран с детальным описанием породы.
- **Таб‑бар** позволяет переключаться между вкладками «Котики» и «Список пород».
- **Экран списка пород** показывает все доступные породы и краткую информацию о них; по тапу открывается детальный экран.
- Используется `http` для запросов к `https://thecatapi.com`, картинки загружаются через `CachedNetworkImage`.
- Обработаны сетевые ошибки: при проблемах показывается диалог с описанием ошибки.
- Подключены `flutter_lints`, код отформатирован через `dart format`.

  - [x] Породы загружаются через endpoint `/breeds`.

### Как запустить проект локально

1. Установите Flutter SDK (стабильный канал, версия 3.x).
2. В корне проекта выполните:

   ```bash
   flutter pub get
   flutter run
   ```

3. При необходимости укажите `THECATAPI_API_KEY` в переменной окружения или в настройках эмулятора (TheCatAPI позволяет использовать и публичный доступ без ключа, но лимиты могут быть ниже).

### Структура проекта (основные файлы)

- `lib/main.dart` — точка входа, навигация, таб‑бар, главный экран, экран списка пород и детальные экраны.
- `lib/models.dart` — модели `CatBreed` и `CatImage` для работы с данными из TheCatAPI.
- `pubspec.yaml` — зависимости (`http`, `cached_network_image`, `flutter_lints`, `flutter_launcher_icons`) и настройки иконки.
- `analysis_options.yaml` — включён `flutter_lints` и дополнительные правила.
